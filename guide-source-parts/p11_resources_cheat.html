23 Every resource worth knowing

Curated links — official, free books, courses, channels, newsletters, communities and practice sites. Nothing here is filler.

23.1 Official — the source of truth

  • docs.python.org/3/ — the reference manual. Start with the Tutorial, then Library Reference. Every answer you will ever need is somewhere in here, with examples.
  • docs.python.org/3/tutorial/ — official tutorial, ~15 chapters, excellent for a first pass.
  • docs.python.org/3/library/index.html — standard library index. Bookmark the “Numeric and Mathematical”, “Data Types”, “File and Directory Access” and “Concurrency” sections.
  • docs.python.org/3/howto/ — focused how-tos: regex, sorting, logging, sockets, functional programming, descriptors, enums, annotations.
  • docs.python.org/3/whatsnew/ — read one per version; the fastest way to learn the language’s evolution (3.11–3.15 especially).
  • peps.python.org — the design documents. Must-reads: PEP 8 (style), PEP 20 (Zen), PEP 257 (docstrings), PEP 484/695 (typing), PEP 703/779 (free-threading), PEP 602 (release cadence).
  • devguide.python.org — how CPython itself is developed, plus the supported-version table.
  • docs.python.org/3/reference/ — the language reference (grammar, data model). Read “Data model” once, properly.
  • packaging.python.org — authoritative packaging guide: pyproject.toml, build backends, publishing.
  • pyfound.blogspot.com — PSF news; python.org/blogs/ — release announcements.
  • Python Packaging Authority (PyPA) on GitHub — pip, setuptools, build, twine, wheel specs.
  • discuss.python.org — where the language is debated. The Ideas and Typing categories are fascinating; searching here beats guessing.

23.4 Blogs, newsletters, podcasts and communities

Read regularly

  • realpython.com/blog — steady stream of high-quality articles.
  • pythonweekly.com — the newsletter to subscribe to (news + releases + articles).
  • PyCoder’s Weekly (pycoders.com) — the other essential weekly.

  • lwn.net and Phoronix — follow CPython perf/ideas when you want depth.
  • Blogs: Ned Batchelder, Brett Cannon, Raymond Hettinger talks, Armin Ronacher, Anthony Shaw, Trey Hunner, Simon Willison (AI + Python).

Ask and discuss

  • discuss.python.org — official, high signal.
  • r/learnpython — beginner help, no gatekeeping; r/Python — news/projects.
  • Stack Overflow — search first; the Python tag FAQ answers most errors.
  • Python Discord (pythondiscord.com) — real-time help, very active.
  • Local & regional communities — PyCon India (Hyderabad/Bengaluru alternating), BangPypers (Bengaluru), PyDelhi, ChennaiPy; most meet monthly and stream talks.
  • Conferences: PyCon US/India/EU, EuroPython, PyData, SciPy — most upload every talk to YouTube, which is a free university.

Awesome lists & curated hubs

  • github.com/vinta/awesome-python — the master index of libraries by category.
  • github.com/awesome-foss/awesome-sysadmin, awesome-data-engineering, awesome-mlops.
  • Python Cheatsheet (gto76.github.io/python-cheatsheet) — dense one-page reference.
  • Python Guide (docs.python-guide.org) — opinionated guide to setup, tooling and structure.

Practice in public

  • Contribute: search GitHub for good first issue language:python; start with docs/tests in a library you use.

  • Build in public: ship small tools to PyPI (uv publish) — packaging teaches you more than any tutorial.
  • Read source: flask, requests, httpx, rich, polars internals, CPython’s Lib/.

24 Roadmaps, cheat-sheets and the index

A plan for the next 90 days, a one-page syntax refresher, and an A–Z index into this guide.

24.1 The 90-day roadmap

The rule that makes it work: after each chapter, write something that uses it. Reading Python is not learning Python. The 90-hour budget is roughly 60% writing code, 25% reading, 15% debugging your own mistakes — and the debugging is where the real learning is.
