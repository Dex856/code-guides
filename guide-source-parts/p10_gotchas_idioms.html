21 Gotchas, traps and “why does it do that?”

Twenty-five behaviours that surprise everyone once. Learn them here instead of in production.

21.1 The hall of fame

1 · Mutable default arguments. 
def bad(x, acc=[]):            # default created ONCE, at def time
    acc.append(x); return acc
bad(1); bad(2)                 # [1] then [1, 2]  ← the same list both times
def good(x, acc=None):
    acc = [] if acc is None else acc
    acc.append(x); return acc
2 · Late-binding closures. 
fns = [lambda: i for i in range(3)]
[f() for f in fns]             # [2, 2, 2] — i is looked up when CALLED
fns = [lambda i=i: i for i in range(3)]     # bind at definition
[f() for f in fns]             # [0, 1, 2]
3 · x = x.sort() / x = x.append(1). 
xs = [3, 1, 2]
xs = xs.sort()                 # xs is now None! sort() sorts in place and returns None
sorted(xs)                     # use this when you want a new list
xs = [3, 1, 2]; xs.sort()      # or call it as a statement
4 · is is not ==. 
a = 257; b = 257
a is b                         # may be False (small ints are cached, big ones are not)
a == b                         # True — compare VALUES with ==
x is None                      # correct: singletons use is
if value is 0: ...             # SyntaxWarning — and semantically wrong
5 · Empty containers are falsy, and 0 == False. 
def render(count=0):
    if count: return "items"   # 0 → "no items"! maybe you meant "is not None"
if not user_input: ...          # treats "" and 0 the same as None
scores = {1: "a", True: "b", 1.0: "c"}    # one key! → {1: 'c'}
6 · Modifying a list while iterating skips items. 
nums = [1, 2, 3, 4]
for n in nums:
    if n % 2 == 0: nums.remove(n)      # ⚠ index shifts under you
nums = [n for n in nums if n % 2]      # build a new list instead
for k in list(d):                      # dicts: iterate over a COPY of the keys
    if d[k] is None: del d[k]
7 · Dict order and set order. 
d = {"b": 1, "a": 2}           # dicts keep INSERTION order (3.7+), not sorted order
list(d)                        # ['b', 'a']
sorted(d)                      # ['a', 'b'] — sort explicitly
{3, 1, 2}                      # sets are unordered and print in arbitrary order
8 · String concatenation in a loop is O(n²). 
s = ""
for w in words: s += w          # quadratic; each += copies the whole string
"".join(words)                  # linear — the correct idiom
9 · float equality and money. 
0.1 + 0.2 == 0.3               # False → 0.30000000000000004
math.isclose(a, b)              # float comparisons
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")     # True — use for money
round(2.5), round(3.5)          # 2 4 — banker's rounding, not "round half up"
10 · Shallow copies keep sharing the inside. 
grid = [[0] * 3] * 3           # ⚠ all three rows are THE SAME list
grid[0][0] = 1                 # [[1,0,0],[1,0,0],[1,0,0]]
grid = [[0] * 3 for _ in range(3)]     # correct
matrix2 = [row[:] for row in grid]     # shallow copy of rows
deep = copy.deepcopy(grid)
11 · Integer division, negative modulo, and chained comparisons. 
7 / 2        # 3.5  (always float)     7 // 2       # 3
-7 // 2      # -4  (floor, not truncate!) -7 % 3    # 2 (sign of the DIVISOR)
int(-7 / 2)  # -3 ← truncation, different from //. Use math.trunc / -(-a // b) deliberately.
0 <= x < 10  # chains correctly (no double evaluation of x)
12 · bool is an int; and/or return operands. 
True + True        # 2
isinstance(True, int)   # True
val = user_input or "default"     # returns 'default' when user_input is falsy (incl. 0!)
count += 1 if found else 0        # ternary needs the else branch
13 · Tuple unpacking counts must match. 
a, b = (1, 2, 3)        # ValueError: too many values to unpack
a, *b = (1, 2, 3)       # a=1, b=[2,3]
x, y = 5                # TypeError: cannot unpack non-iterable int
one = (5,)              # a 1-tuple needs the comma — (5) is just 5
14 · global vs nonlocal, and reading before assigning. 
total = 0
def add(n):
    total += n          # UnboundLocalError! Python sees the assignment → total is local
def add(n):
    global total; total += n        # explicit
def outer():
    n = 0
    def inner():
        nonlocal n; n += 1          # rebinds the enclosing scope
15 · except Exception does not catch everything — and finally: return eats exceptions. 
try: sys.exit(0)
except Exception: pass       # SystemExit is BaseException → NOT caught
def f():
    try: raise ValueError("boom")
    finally: return 1        # swallows the exception; 3.14 warns on this (PEP 765)
raise NewError(str(e))       # loses the traceback → use `raise NewError(...) from e`
16 · Assertions disappear with -O. 
assert user.is_admin         # gone when running python -O (production optimised)
if not user.is_admin: raise PermissionError   # real checks must be real code
17 · Class attributes are shared — until you assign. 
class C:
    items = []               # ⚠ shared by every instance
a, b = C(), C()
a.items.append(1)            # b.items is [1] too!
class C:
    def __init__(self): self.items = []       # per instance — correct
18 · Method resolution and super() in multiple inheritance. 
class A:
    def ping(self): print("A")
class B(A):
    def ping(self): super().ping(); print("B")
class C(A):
    def ping(self): print("C")          # note: no super() call → breaks the chain
class D(B, C): pass
D().ping()      # C, B — because C does not cooperate. Always call super() in mixins.
19 · += on lists mutates; on tuples/strings it rebinds. 
a = b = [1]
a += [2]        # list.__iadd__ mutates in place → b is [1, 2]
a = b = (1,)
a += (2,)       # rebinds a new tuple → b still (1,)
t = ([1],)
t[0] += [2]     # TypeError AND the list got mutated — the famous tuple trap
20 · Module-level code runs on import (and runs once). 
# utils.py
print("loading")            # runs at import — annoying side effect
cache = {}                  # shared, process-wide mutable state
# Importing utils from five modules prints once; the same cache object is shared.
21 · Files, encodings and line endings. 
open("data.csv").read()                       # locale encoding — may crash on UTF-8
open("data.csv", encoding="utf-8")            # explicit
open("data.csv", newline="")                  # required for the csv module
open("x")                                     # never forget to close → use `with`
22 · datetime.utcnow() is deprecated and naive. 
datetime.utcnow()                              # ❌ naive, deprecated
datetime.now(timezone.utc)                     # ✅ aware
dt.isoformat()                                 # serialise with offset
dt.astimezone(ZoneInfo("Asia/Kolkata"))        # convert for display only
23 · Threads + shared counters. 
counter = 0
def bump():
    global counter
    counter += 1            # read-modify-write: NOT atomic, even with the GIL
# 10 threads × 1000 bumps ≈ 8200 instead of 10000. Guard with a Lock, or use a queue.
24 · JSON keys, serialisation and non-string types. 
json.dumps({1: "a"})            # '{"1": "a"}' — keys become strings
json.loads('{"1": "a"}')[1]     # KeyError — the key is "1", not 1
json.dumps({"t": datetime.now()})   # TypeError → default=str or an encoder
json.dumps({"f": float("nan")})     # 'NaN' — invalid strict JSON; use allow_nan=False
25 · Iterators are single-use (and zip/map/filter are lazy). 
zs = zip(a, b)
list(zs)        # [(...), ...]
list(zs)        # [] ← already consumed! re-create it or materialise once
gen = (x for x in data)
sum(gen); len(list(gen))    # 0 — same trap with generators
zip(a, b)                   # stops at the shortest by default → zip(a, b, strict=True) raises

22.2 Interview questions — with answers

Language fundamentals

1. Is Python interpreted or compiled? Both: source is compiled to bytecode (.pyc) and that bytecode is executed by the CPython virtual machine. 3.13+ adds an optional JIT.

2. List vs tuple vs set vs dict — when do you use each? list: ordered, mutable sequence · tuple: fixed record, hashable · set: uniqueness and membership · dict: key→value mapping with O(1) lookup. (Table in ch. 5.2.)

3. Shallow vs deep copy? Shallow copies the outer container but shares the inner objects; deepcopy recursively copies everything. l2 = l1.copy() then l2[0].append(x) still changes l1.

4. What does if __name__ == "__main__" do? Runs the block only when the file is executed directly, not when imported — enabling dual use as script and module, and required for safe multiprocessing on spawn platforms.

5. is vs ==? Identity (same object) vs value equality. Use is only for singletons (None, True, False, sentinels) — interning makes is unreliable for values.

6. Why are default arguments evaluated once? They are stored on the function object at definition time (f.__defaults__), so mutable defaults are shared across calls — the classic bug.

7. What is a closure? A nested function that captures variables from its enclosing scope; the cell survives after the outer function returns. Combined with late binding, this powers decorators.

8. Explain LEGB. Local → Enclosing → Global → Builtins name resolution; assignment makes a name local unless declared global/nonlocal.

9. What are *args and **kwargs? Positional and keyword variadic parameters; * also unpacks at call sites, and * alone in a signature marks keyword-only parameters.

10. Are Python strings mutable? What about bytes? No — both immutable. All “modifying” methods return new objects; build with join or bytearray.

Data model, OOP and typing

11. What are dunder methods? Give useful examples. Hooks the language calls: __init__, __repr__, __eq__/__hash__, __len__, __getitem__, __iter__, __enter__/__exit__, __call__, __add__.

12. If you define __eq__, what else must you define? __hash__ (or set it to None to make instances unhashable), otherwise equal objects can have different hashes and break dicts.

13. How does super() work? It returns a proxy that dispatches to the next class in the MRO, not necessarily “the parent” — which is why cooperative multiple inheritance requires *args, **kwargs pass-through.

14. Composition vs inheritance? Prefer composition; inherit for genuine “is-a” plus shared implementation. Use Protocols/ABCs to define interfaces instead of deep hierarchies.

15. What is a property? A computed attribute implemented via the descriptor protocol; allows validation and lazy computation behind plain attribute access.

16. Difference between @staticmethod, @classmethod, instance method? No self, gets cls (alternative constructors, polymorphic factories), or gets the instance.

17. When use __slots__? Many small objects, tight memory: removes per-instance __dict__ and speeds attribute access; costs flexibility (no dynamic attributes, needs care with inheritance and pickling).

18. What does “duck typing” mean, and how do Protocols improve it? Behaviour over type: if it walks and quacks… typing.Protocol expresses that structurally so type checkers can verify it without inheritance.

19. Are type hints enforced at runtime? No. They are checked statically by mypy/pyright or validated at runtime by libraries like pydantic.

20. What is a metaclass? The class of a class — controls class creation (type subclass, __init_subclass__, __prepare__). Rarely needed; use __init_subclass__ or decorators first.

Runtime, memory and concurrency

21. What is the GIL and why does it exist? A lock allowing one thread at a time to execute Python bytecode, protecting reference counting and C extension assumptions. It is released during I/O and by C code that opts out. 3.14 ships officially supported free-threaded builds (PEP 703/779) where it is removed.

22. Threads vs processes vs asyncio? Threads for I/O-bound work with blocking libraries (shared memory, GIL limits CPU) · processes for CPU-bound parallelism (separate interpreters, pickle IPC) · asyncio for thousands of concurrent I/O operations in one thread with cooperative scheduling.

23. Does the GIL make code thread-safe? No. x += 1 is multiple bytecodes — races still happen. Protect shared state with locks (or avoid sharing).

24. How does CPython manage memory? Reference counting frees objects immediately at zero refs, plus a generational cycle collector for reference cycles; 3.14 made collection incremental to reduce pauses.

25. What is the difference between __del__ and a context manager? __del__ timing is unspecified and may never run; with guarantees cleanup deterministically.

26. Generators vs lists? Generators are lazy, single-use, O(1) memory, and can represent infinite sequences; lists are materialised, indexable and reusable.

27. What is a decorator and how do you write one that takes arguments? A callable that returns a replacement for the decorated object; with arguments it becomes a three-level closure (retry(times=3) → decorator(func) → wrapper(*a, **kw)), ideally @wraps(func)-preserved.

28. How would you find a performance bottleneck? Measure first: cProfile/py-spy to find the hotspot, line_profiler for the line, tracemalloc/memray for memory; then fix the algorithm, push loops into C, batch I/O, and parallelise last.

29. What happens when you import a module twice? The second import is a no-op: the module object is cached in sys.modules. Its top-level code runs exactly once per process (importlib.reload forces re-execution).

30. How do you handle secrets and configuration? Environment variables or a secret manager, loaded into typed settings (pydantic-settings), never committed; .env.example documents the shape; rotate anything that ever touched git.

# 1  Reverse words in a sentence, preserving spaces collapsed
def rev_words(s: str) -> str: return " ".join(reversed(s.split()))

# 2  Count character frequency, most common first
from collections import Counter
def freq(s: str): return Counter(s).most_common()

# 3  Two-sum with a hash map — O(n)
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if (need := target - n) in seen:
            return (seen[need], i)
        seen[n] = i

# 4  Flatten one level / deep-flatten recursively
def flatten(nested):
    return [x for sub in nested for x in sub]
def deep_flatten(x):
    if isinstance(x, (list, tuple)):
        for item in x: yield from deep_flatten(item)
    else: yield x

# 5  Group by a key
from collections import defaultdict
def group_by(rows, key):
    g = defaultdict(list)
    for r in rows: g[key(r)].append(r)
    return dict(g)

# 6  Memoised Fibonacci with an lru_cache (and why it is linear)
from functools import cache
@cache
def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)

# 7  Read a file and yield parsed records lazily
def records(path):
    with open(path, encoding="utf-8") as fh:
        header = next(fh).rstrip().split(",")
        for line in fh: yield dict(zip(header, line.rstrip().split(",")))
