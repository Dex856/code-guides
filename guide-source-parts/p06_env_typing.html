12.1 Version specifiers — what >=1.2,<2 actually means

Semantic versioning (semver): MAJOR.MINOR.PATCH — major = breaking, minor = backwards-compatible features, patch = backwards-compatible fixes. Not all projects follow it faithfully; pre-1.0 libraries are allowed to break in minor releases. 0.x means unstable by convention.

12.3 Shipping: apps vs libraries

Application

You control the environment. Pin tightly, commit the lock file, containerise.

FROM python:3.14-slim
COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv
WORKDIR /app
ENV UV_COMPILE_BYTECODE=1 UV_LINK_MODE=copy
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-dev --no-install-project
COPY . .
RUN uv sync --frozen --no-dev
CMD ["uv", "run", "python", "-m", "myapp"]

Multi-stage builds, non-root user, .dockerignore out .venv and .git. Pin the base image digest for reproducibility.

Library

Others control the environment. Loosen your constraints, test the matrix, never pin transitives.

[project]
name = "my-lib"
requires-python = ">=3.10"        # support a range
dependencies = ["httpx>=0.27"]    # lower bound only

[dependency-groups]
dev = ["pytest", "ruff", "mypy",
       "tox", "build", "twine"]

[project.optional-dependencies]
cli = ["typer>=0.12"]
test = ["pytest>=8"]

Add CI that tests 3.10 → 3.14 (and free-threaded), ship py.typed, keep a changelog. uv build → uv publish (or twine upload dist/*).

13 Type hints and modern typing

Types are documentation the computer can check. Here is the 20% of the typing system that covers 95% of real code.

13.1 The basics: annotate everything public

# Simple forms
name: str = "Ada"
count: int = 0
ratio: float = 1.5
flag: bool = True
nothing: None = None
anything: object = get_thing()          # object = "any non-None Python value"
untyped: Any = anything                 # opt out of checking (use sparingly)

# Collections — prefer the abstract type for parameters, concrete for returns
names: list[str] = ["a"]
lookup: dict[str, int] = {"a": 1}
pair: tuple[int, str] = (1, "x")
coord: tuple[float, float, float] = (1.0, 2.0, 3.0)   # fixed length/positions
variadic: tuple[int, ...] = (1, 2, 3)                 # any length
unique: set[str] = {"a"}
frozen: frozenset[int] = frozenset({1})

# Optional & unions
maybe_id: int | None = None                            # modern (3.10+)
result: int | str | None = None
legacy: Optional[Union[int, str]] = None               # pre-3.10 style, same meaning

# Callables and iterables
from collections.abc import Callable, Iterable, Sequence, Mapping, Iterator, Hashable, Awaitable
Transform = Callable[[int, str], bool]                 # (int, str) -> bool
fn: Callable[..., int] = len
def take(xs: Iterable[int]) -> Iterator[int]: ...       # ← best parameter types
def head(xs: Sequence[int]) -> int: return xs[0]        # Sequence = indexable + len
d: Mapping[str, int] = {}

# Classes and generics (PEP 695 syntax, 3.12+)
class Stack[T]:                                        # generic class
    def __init__(self) -> None: self._items: list[T] = []
    def push(self, item: T) -> None: self._items.append(item)
    def pop(self) -> T: return self._items.pop()

def first[T](xs: Sequence[T]) -> T: return xs[0]        # generic function

type Vector = list[float]                              # type alias (3.12+)
type Matrix = list[Vector]
type Json = dict[str, "Json"] | list["Json"] | str | int | float | bool | None

# Literal, Final, TypedDict, NamedTuple
from typing import Literal, Final, TypedDict, NotRequired, Self, Protocol, Annotated
def align(pos: Literal["left", "center", "right"] = "left") -> None: ...
MAX_RETRIES: Final = 5                                  # cannot be reassigned (checked)

class Movie(TypedDict):
    title: str
    year: int
    rating: NotRequired[float]                          # dict shape with types

class Closeable(Protocol):                              # structural typing
    def close(self) -> None: ...

class Builder:
    def add(self, x: int) -> Self:                      # fluent API, subclass-safe
        return self

UserId = Annotated[int, "must be > 0"]                  # attach metadata/documented constraints
NeedUse
“some common type”Callable, Iterable, Sequence, Mapping, Hashable
“one of these exact strings”Literal["a", "b"]
“a fixed-shape dict”TypedDict
“duck-typed interface”Protocol
“this or that”A | B
“a specific subtype”TypeVar / PEP 695 [T]
“must be a class, not an instance”type[X]
“I really cannot type this”Any (and move the check elsewhere) — never sprinkle everywhere

13.2 Narrowing, overloads and generics in practice

# Narrowing: type checkers follow isinstance / in / is None / hasattr / match
def describe(x: int | str | None) -> str:
    if x is None:
        return "nothing"                    # here x: None
    if isinstance(x, int):
        return f"int {x + 1}"               # here x: int
    return x.upper()                        # here x: str

# assert_never-style exhaustiveness (typing.assert_never)
from typing import assert_never
def handle(state: Literal["new", "done"]) -> str:
    match state:
        case "new": return "queued"
        case "done": return "closed"
        case _: assert_never(state)         # fails type checking if you add a state

# Overloads: same function name, different accepted/returned types
from typing import overload
@overload
def parse(value: str) -> str: ...
@overload
def parse(value: int) -> int: ...
def parse(value: str | int) -> str | int:      # the real implementation
    return value

# TypeVar with constraints vs bound
from typing import TypeVar
Number = TypeVar("Number", int, float)          # constrained: exactly these
Comparable = TypeVar("Comparable", bound="SupportsRichComparison")
def biggest(a: Number, b: Number) -> Number: return a if a > b else b

# ParamSpec and TypeVarTuple for decorator/varargs typing
from typing import ParamSpec, Concatenate
P = ParamSpec("P"); R = TypeVar("R")
def logged(fn: Callable[P, R]) -> Callable[P, R]:
    @wraps(fn)
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        print(fn.__name__)
        return fn(*args, **kwargs)
    return wrapper

# Type-only imports to avoid cycles and import cost
from typing import TYPE_CHECKING
if TYPE_CHECKING:
    from .heavy import Model          # never imported at runtime
def use(m: "Model") -> None: ...

13.3 Runtime validation: annotations that actually run

# Type hints are not enforced — use a validation library at the edges of your system
from pydantic import BaseModel, Field, field_validator, ConfigDict
from datetime import date

class Order(BaseModel):
    model_config = ConfigDict(extra="forbid", str_strip_whitespace=True)

    id: int
    sku: str = Field(min_length=2, max_length=32, pattern=r"^[A-Z0-9-]+$")
    qty: int = Field(gt=0, le=10_000)
    placed: date
    tags: set[str] = set()

    @field_validator("sku")
    @classmethod
    def upper(cls, v: str) -> str:
        return v.upper()

order = Order.model_validate_json('{"id": 1, "sku": "a1", "qty": 2, "placed": "2026-10-02"}')
order.sku            # 'A1' — coerced and validated
order.model_dump()   # plain dict, JSON-ready

# FastAPI is built on exactly this: your annotations become docs, validation and serialisation
from fastapi import FastAPI
app = FastAPI()

@app.post("/orders", response_model=Order)
def create(order: Order) -> Order:          # request is validated, response is typed
    return order
